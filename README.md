## A hand-controlled Spotify playlist:
- Too lazy to click one button to skip songs or adjust the volume? How about you open a whole website and wave your hands in the air?

- Mediapipe hand landmaker + Spotify API project: A one-time CLI configuration allows you to link your profile and pick your favorite playlist (let's be honest, who ACTUALLY listens to multiple playlists at once), and a default device.
- The songs are then displayed in a 3d carousel built in three.js, the carousel is controllable through horizontal movement of the right index to select songs, and vertical movement to adjust radius for better vision. A pinch motion with the left hand adjusts the volume.

- Learning objectives: 3d modeling in three.js, recalling API workflow, and testing mediapipe for other potential projects.
